Detailed Description

Abstract visitor with one operation applied to either a WorkFlow or a WorkItem.

Concrete visitors implement one state transition each (begin, review, approve, finish, cancel). A component calls its visitor through WorkFlowComponent::accept(), which gives double dispatch.
