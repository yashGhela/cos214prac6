Detailed Description

Observer that takes the role of the normal observer so incoming actions are handled uniformly.

update() is a Template Method: it checks shouldReact(), then calls applyAction(), then afterUpdate(). Subclasses customise those steps. A general WorkFlowObserver is kept as the base so the design can still be expanded with other kinds of observer.
