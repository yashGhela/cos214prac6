Detailed Description

Simple interface that hides the visitors, mementos, participants and handler chain behind a few calls.

Owns the current workflow and the version history. Participants, the handler chain and the observer are stored but not owned. Every workflow operation prints a message and does nothing if no workflow has been created yet.
