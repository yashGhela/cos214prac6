Detailed Description

template<typename T>
class HandlerTemplate< T >

Concrete handler in the chain that is also an observer.

Acts as a WorkHandler (Chain of Responsibility) and as an ActionObserver (Observer). The actual processing is delegated to an optional ProcessHandler.

Template Parameters
TType used to specialise the handler.
