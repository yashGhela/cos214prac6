Detailed Description

A named event that carries an action and the list of observers reacting to it.

Users can create their own events with a unique name and an ActionRegistry value and pass them around seamlessly. An EventSubject attaches observers to an Event and notifies them when the event fires.

Note
The Event does not own its observers; it only stores raw pointers.
